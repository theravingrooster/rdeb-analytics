Computational research portfolio

Public-data analyses of RDEB

Proof-of-concept computational work on recessive dystrophic epidermolysis bullosa, using public datasets only.

Each project starts from a published gene-expression series, loads it with a notebook, and records only the steps that have actually been run. The first project is a quality-control pass on a public microarray study of RDEB skin. Differential expression and the steps after it are still ahead.

Public datasets only. No patient data or protected health information.
